## 目的と範囲

確認済みの P0、P1、P2 の品質改善を PR でレビューし、`takachino/NBLM2PPTX` の `feat/multilingual-ja` へ反映する。

比較資料を公開する場合は、再配布可能な合成入力を使う。

## 反映先と依存関係

ユーザーが `takachino/NBLM2PPTX` の `feat/multilingual-ja` を反映先として指定した。
このフォークには ADMIN 権限があり、対象ブランチは開始時点で `dc8230b`、保護なしである。
本家の `main` と既存 PR #6〜#10 には今回の作業で変更を加えない。

品質改善の基点 `dc8230b` には、GUI 多言語化、OCR 言語、東アジアフォント、回転文字の変更が含まれる。
これらに対応する本家 PR #6〜#10 は、開始時点ですべて未マージである。
反映先には基点までの変更がすでに含まれるため、P0、P1、P2 の順に三つの PR を作成する。
各 PR のベースは `feat/multilingual-ja` とし、順にマージして前段の変更を差分から除く。
履歴を維持するため通常のマージコミットを使う。

## 手順

1. 反映先、権限、既存 PR、ブランチの依存関係を確認する。
2. P0 の背景補間、P1 の記号と UI 保護、P2 の OCR・配置・書式を順にレビューする。
   修正が必要な場合は、失敗する回帰テストを先に追加する。
3. 低い並列度でワークスペースのテスト、整形、Clippy を実行する。
   PowerPoint 互換性と既存 fixture の画像差分を確認する。
   PowerPoint の保存・画像書き出しは行わない。
4. レビュー対象、比較資料、検証結果、既知の制約を PR 本文にまとめる。
5. PR を作成し、差分とチェックを確認してから、指定ブランチへ順にマージする。
6. `feat/multilingual-ja` のコミットと作業ツリーを確認し、計画へ結果を記録する。
