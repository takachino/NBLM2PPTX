# 低信頼度 OCR とフォント・部分強調の改善

作成日: 2026-10-27
基準: ユーザーが確認した `archive/quality/p2-ocr-placement/revised.pptx` と `2734b67`。

## 調査で分かったこと

9 ページの `Unlwerk` は元画像にも同じ字形がある。
同じ枠の一部は元画像そのものが崩れており、意味から別の単語へ置き換える根拠はない。
認識候補だけで本文を推測せず、切り出しと異なる拡大率の再認識の一致を使う。
現在のフォントは欧文と日本語の両方が Noto Sans JP、字重は行全体の面積比で決まる。
単一行の中にある強調と通常文字を分ける出力はまだない。

## 実施順序

1. 低信頼度の行を切り出し、拡大率と文脈の違いで候補が安定するか調査する。
   元画像で判読できる文字と、原稿自体の不鮮明さを区別する。
2. 同じ位置の行を二つの再認識で照合し、信頼度が改善し、文字列と範囲が一致する場合だけ採用する。
   異なる行の混入、低信頼度のままの結果、互いに矛盾する結果を棄却するテストを先に追加する。
   再認識回数を制限し、採否と元の文字列を診断へ保存する。
3. フォントの差を観測幅と画素の筆画で評価する。
   原稿から名前を断定せず、利用できるフォントや字重で再現できる差に絞る。
   画像の不確かな単語をフォント推定の根拠にしない。
4. 文字単位の筆画幅などから、同じ行内で明確に異なる字重を検出する。
   OOXML の複数 run へ反映し、文字の欠落や重複、通常文字の誤強調、混在文字幅の回帰テストを追加する。
5. 全 14 ページを変換し、確認済みの OCR・配置・保護画素を照合する。
   PowerPoint の描画範囲、互換性、既存画像差分、ワークスペースのテスト、整形、Clippy を確認する。
6. 別の成果物ディレクトリへ確認用 PPTX を保存し、実装結果と確定できない原稿の箇所を記録する。

## 実装と検証結果

低信頼度の行を、元の画素から切り出した 2 倍・3 倍の画像で再認識した。
対象は文字を含む水平行、ページ高の 1.8% 以上、信頼度が 0.8 未満、1 ページ最大 12 観測。
同じ位置の一行、文字列の一致、両方が 0.9 以上、元から 0.2 以上改善、文字の差が限定的であることを採用条件にした。
正しい補正が失敗するテストを先に追加し、不一致・低信頼度・別の本文への変化を棄却する対照テストも追加した。
9 ページの「カスタムアプリ開発」、10 ページの「統合」、11 ページの「膨大」を補正した。
83 観測で再認識を試し、文字変更 3 観測と信頼度だけ改善した 1 観測を採用した。
採用しなかった候補と理由も診断へ記録する。

インストール済みの通常字形と太字を ab_glyph で描画して比較し、42 個の文字枠の字重を更新した。
短い文字列の画数差を強調と誤判定した初期案は棄却した。
原稿の主な文字帯を選び、字形の縦横比で文字を対応させ、項目名と説明文の字重差を複数文字で確認するようにした。
12、14 ページの計 5 箇所で同じ行の項目名を太字、説明文を通常字として出力した。
14 ページは「拡張エコシステム」「データモデル」「インフラストラクチャ」の 3 項目。
フォントファミリーの変更は最終版では採用されず、Noto Sans JP を維持した。
原稿は画像なので元のフォント名は確定できず、字形と字重の差を比較対象にした。

OOXML に太字指定を持つ複数 run を追加した。
通常字へ戻す run は `b="0"` を明示し、文字列が一致しない古い run が残っていても編集後の本文を欠落させない。
通常字と太字、改行と段落、編集後の文字列を確認するテストを追加した。
比較用フォントファイルは読み取りのみで、新しいフォント素材をソースや PPTX に含めていない。
